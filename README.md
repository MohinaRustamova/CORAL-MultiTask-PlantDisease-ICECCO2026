# CORAL-MultiTask-PlantDisease-ICECCO2026


Code for the paper:
**"Multi-Task Learning With CORAL-Based Feature Alignment for Cross-Domain Plant Disease Detection"**
Rustamova M., Kadyrov S., Baimukashev R. — ICECCO 2026, IEEE.

📄 Published: https://ieeexplore.ieee.org/document/11488762

---

## Overview

This repository documents the implementation of my first conference paper, presented at the 18th International Conference on Electronics, Computer, and Computation (ICECCO 2026), Kaskelen, Kazakhstan.

The work proposes a multi-task learning framework with CORAL-based feature alignment for cross-domain plant disease detection, transferring from PlantVillage (source) to PlantDoc (target) under domain shift conditions.

---

## Repository Structure

```
└── domain_shift_plantvillage_plantdoc.ipynb   # Main training and evaluation notebook
```

Designed to run on **Google Colab** (GPU recommended).
Dependencies are installed in the first cell of the notebook.
